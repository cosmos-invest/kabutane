# 初心者向けサイト再整理

## 目的

機能を増やすのではなく、既存情報を毎回同じ順序で読めるようにする。初心者が一つの指標だけで売買を決めず、「観察する・待つ・見送る」も選べる状態を完成とする。

## 診断

かぶたねには月足RSI、日足チャート、価格帯別出来高、財務、信用需給、大量保有報告、売買練習がそろっている。一方、入口が機能名ごとに並ぶと、初心者には「どれから見るか」「情報同士をどうつなぐか」が分かりにくい。課題は機能不足ではなく、情報の順番である。

## 共通の4ステップ

1. **値動きはどう？** 日足、出来高、SMA、月足RSIで方向と勢いを見る。
2. **会社の体力は？** 売上成長、ROE、自己資本、フリーCFを中心に見る。
3. **需給は重くない？** JPXの信用買い残・売り残を、価格と同じ期間で見る。
4. **大口はなぜ動いた？** EDINETの提出者、目的、保有割合の変化を最後に重ねる。

大量保有の増加は買い推奨ではなく、減少は売却・空売りの断定ではない。信用売り残と機関投資家の空売り残高も別制度であり、現在のかぶたねには後者の推移は未搭載と明記する。

## 3人の役割

- **ルーモ**: 数字やチャートの変化を見つける。
- **エール**: 財務、需給、判断の抜けやリスクを確認する。
- **コスモス**: 複数材料をつなぎ、買う以外の結論も整理する。

全銘柄一覧の既存フィルターは、コスモス＝王道トレンド、ルーモ＝動き出し、エール＝財務という入口として維持する。案内役とスクリーニング条件を混同しない。

## 情報の深さ

- 最初に見る: 4つの問いと短い結論。
- 必要になったら見る: POC、バリューエリア、詳細な報告目的、過去GC実績。
- 慣れた人が見る: 玄人向け条件、リプレイ、バックテスト、ランキング。

高度な機能は削除せず、折りたたみや「もっと使う」に置く。公開全銘柄から暫定GCを発見する機能はプレミアム境界を維持する。

## 具体例

大口の保有割合が増えていても、日足が下降、フリーCFが赤字、信用買い残が急増していれば待つ。反対に、値動き、会社、需給、大口の説明がそろえば観察候補に残す。ただし上昇後を追わず、入口・損切り・最大損失を決めて売買練習へ進む。

## ページごとの役割

- ホーム: 4つの問いと3人の役割を最初に示す。
- 全銘柄: 買う場所ではなく、3〜5社へ絞る場所にする。
- 個別詳細: 4ステップの順番どおりに情報を並べる。
- 気になる株: 保存理由が残っているかを同じ4ステップで再確認する。
- 大口保有: 誰が、なぜ、どう変えたかに絞り、全文は折りたたむ。
- 学び・使い方: 用語集ではなく、4ステップの読み方と具体例を教える。
- 売買練習: 分析後に入口、損切り、株数、利確を試す。

## 完成条件

- 主要画面で4ステップの名称と順序が一致する。
- 既存のDOM IDとJavaScript連携を壊さない。
- 大口情報だけで売買を断定しない説明がある。
- 信用売り残と機関空売りを混同しない。
- PWAから初心者ルートへ直接入れる。
- 暫定GCの公開・プレミアム境界を維持する。
