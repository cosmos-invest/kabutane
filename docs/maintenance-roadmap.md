# かぶたね 保守・アップデート方針

## 絶対条件

- 新規の月額利用料、有料API、有料インフラを前提にしない。
- 無料で成立しない機能は、代替案を検討し、代替がなければ見送る。
- 既存機能への影響を自動テストで確認してからマージする。

## 優先順位

1. 全体回帰テスト基盤
2. データSchema契約
3. 日次Snapshot
4. 差分Event Engine
5. 価格帯別出来高
6. 資金管理・購入株数ナビ
7. 信用需給 v1（無料で取得可能な範囲）
8. 今日のかぶたね（日次サマリー）
9. 信用需給 v2（日次化後も無料取得できる範囲のみ）
10. 月次答え合わせ
11. 無料で取得可能な一次情報ニュース連携
12. ポートフォリオ・投資記録

## 今回追加する無料一次情報

- EDINETの大量保有報告書・変更報告書を、APIキーを端末内だけで入力して取得する。
- 新規5%超、保有割合の増加・減少、重要提案行為等、訂正を分類する。
- 増加を「買い」、減少を「売り・空売り」と断定しない。
- GitHub Actionsの定期実行は追加せず、当面はTermuxから手動生成する。

## 保留するもの

- 機関の空売り残高：無料一次情報の取得条件・再配布条件・安定性を別途確認してから判断する。
- TDnet適時開示の全文取得・再分類：アクセス条件・利用規約・安全な取得経路を確認できるまで実装しない。
- 決算増益、増配、上方修正の自動一覧：TDnet連携を保留するため、誤判定を避けて今回は追加しない。

## 差し込みルール

使いながら見つかったUI改善、追加情報、分析視点は随時バックログへ追加する。毎回、資産形成への寄与、利用頻度、実装リスク、既存機能への影響、ゼロコスト条件で優先順位を再評価する。
