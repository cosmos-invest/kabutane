# かぶたね アクセス境界

かぶたねは、公開機能・ROOM観察室・管理領域を混ぜない。

## 1. 公開エリア

- `index.html` を中心とする通常のかぶたね。
- 誰でも利用できる銘柄探し、個別確認、学習、売買練習などを置く。
- 公開ナビゲーションからROOM専用ページへの通常導線は出さない。

## 2. ROOM観察室

- 入口は `premium-supply-beta.html`。表示名は「ROOMメイト専用｜かぶたね観察室」。
- `premium-etf-pcf.html` などROOM内の子ページも同じ入室状態を共有する。
- 合言葉は `data/room-access.json` のSHA-256ハッシュと照合し、平文をHTML/JavaScriptへ置かない。
- 「この端末で覚えておく」を選んだ場合は最長30日、選ばない場合はブラウザセッション中だけ入室状態を保持する。
- 合言葉を更新するときはハッシュだけでなく `version` も更新する。これにより旧バージョンの保存済み入室状態を失効させる。
- ROOMページは `noindex,nofollow,noarchive` とし、公開ナビゲーションからリンクしない。
- URL・合言葉の転載は禁止転載を案内する。

### 重要な制約

現在はGitHub Pages上の静的JavaScriptによる簡易ゲートであり、厳密な会員認証ではない。公開リポジトリや配信ファイルを直接調査できる利用者に対して、データそのものを秘匿する仕組みではない。

そのためROOMには、公開されても重大事故にならない観察・仮説・検証用データだけを置く。個人情報、会員情報、非公開アクセスログ、秘密鍵、APIキーなどを置かない。

## 3. 管理領域

- コスモス本人だけが確認するアクセスログ、利用状況、内部分析、会員識別情報などはGitHub Pagesへ公開しない。
- 管理領域へのリンクをROOMページや公開ページへ追加しない。
- 管理画面が必要になった場合は、Cloudflare Access、サーバー側セッション認証、認証付きホスティングなど、配信前に認証できる仕組みへ分離する。
- GitHubリポジトリがpublicの間は、管理用データそのものもリポジトリへcommitしない。

## noteからの入室導線

1. noteのメンバー限定記事または固定投稿から `premium-supply-beta.html` を開く。
2. ROOM専用の合言葉を入力する。
3. 必要なら「この端末で30日間覚えておく」を選ぶ。
4. かぶたね観察室と、その配下のROOMページを利用する。

合言葉はnote側のROOM限定記事または固定投稿で案内する。
